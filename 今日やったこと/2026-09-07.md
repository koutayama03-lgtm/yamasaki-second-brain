## 3. 詰まったところと解説

### ① リモート追加時の「invalid refspec 'master:https://...'」
**症状**：Obsidian GitのUIから「リモートURLを入力する」欄にURLを入力したが、正しくリモートURLとして認識されず、pushコマンド内で `master:https://...` という形でブランチ名の一部として扱われてしまった。

**原因**：プラグインのUI上での入力フローが噛み合わなかったため（プラグイン側の分かりにくさによるもので、操作ミスというより仕様上のクセ）。

**対処**：ターミナルから直接、以下を実行してリモートを設定し直した。
```
git remote remove origin
git remote add origin https://github.com/koutayama03-lgtm/yamasaki-second-brain.git
```

### ② commit時の「Author identity unknown」
**症状**：`git commit` 実行時に、commitする人物の名前・メールアドレスが未設定であるというエラーが発生。

**原因**：このPCでgitを使うのが初めてで、ユーザー情報（identity）を一度も設定していなかったため。

**対処**：
```
git config --global user.name "koutayama03"
git config --global user.email "koutayama03@gmail.com"
```
を実行し、identityを設定。以降のcommitで発生しなくなった。

### ③ push時の「fatal: couldn't find remote ref HEAD」
**症状**：Obsidian内のコマンドパレットから「Git: Push」を実行した際に発生。

**原因**：GitHub側のリポジトリが完全に空の状態（ブランチが一つも存在しない）だったため、プラグインがpush前にリモートの基準ブランチ（HEAD）を参照しようとして見つけられず失敗した。空リポジトリに対する初回push特有の挙動。

**対処**：ターミナルから直接、以下を実行してリモートに最初のブランチを作成した。
```
git push -u origin master
```
これによりリモート側にHEADが生まれ、以降はObsidian内のプラグイン操作だけで問題なくpushできるようになった。

### ④ push時の「src refspec master does not match any」
**症状**：`git push -u origin master` を実行した際に、ローカルに `master` というブランチが存在しないというエラーが発生。

**原因**：②のidentity未設定エラーでcommit自体が失敗しており、`master` ブランチがまだ一度も作られていなかったため。

**対処**：②を解消してcommitを完了させたことで、`master` ブランチが作成され解決した。
